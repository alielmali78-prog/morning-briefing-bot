## 🎯 What is this?

A personal AI-powered morning briefing system that delivers:

- Global news
- Executive summary
- AI & Cloud insights
- Weather
- Learning snippets

directly to Telegram every morning at 05:30.

## 🚀 Why I built this?

To create a personal executive assistant that filters noise and delivers only what matters.

## 🛠 How it works?

- RSS feeds → News
- OpenAI → Summary
- Telegram API → Delivery
- Cron → Automation

# 🧠 Morning Briefing Bot

Automated executive morning briefing system delivered via Telegram.

## 🚀 Features

- 🌍 Global news headlines (Google News RSS)
- 🧠 Executive summary
- ☁️ AI & Cloud radar
- 🌤 Istanbul weather
- 🇬🇧 English booster (phrasal verbs)
- 📖 Daily Quran verse
- 📚 Book recommendation
- ✍️ Optional poetry

## 🛠 Tech Stack

- Python 3
- Telegram Bot API
- Cron (Linux scheduling)
- RSS feeds
