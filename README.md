# 🧠 Morning Briefing Bot

Automated executive morning briefing system delivered via Telegram.

## 🚀 Features

- 🌍 Global news headlines (Google News RSS)
- 🧠 Executive summary
- ☁️ AI & Cloud radar
- 🌤 Istanbul weather
- 🇬🇧 English booster (phrasal verbs)
- 📖 Daily Quran verse
- 📚 Book recommendation
- ✍️ Optional poetry

## 🛠 Tech Stack

- Python 3
- Telegram Bot API
- Cron (Linux scheduling)
- RSS feeds

## ⚙️ Setup

```bash
pip install -r requirements.txt
python3 morning_brief.py
